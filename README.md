# MetaClean Web

Static website for MetaClean, including the public privacy policy required for App Store distribution.

## Files

- `index.html` — privacy site homepage
- `privacy-policy.html` — MetaClean privacy policy

## Hosting

This repository is designed to be published with GitHub Pages.

## Analytics

Google Analytics should be added to the website only after the GA4 Measurement ID is created. Keep analytics limited to the website; the MetaClean iOS app remains analytics-free for the current MVP unless explicitly reviewed and approved.
