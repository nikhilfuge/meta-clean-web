# MetaClean Web

Public privacy policy for MetaClean, required for App Store distribution.

## Files

- `privacy-policy.html` — MetaClean privacy policy, published at
  https://nikhilfuge.github.io/meta-clean-web/privacy-policy.html (linked from the app's
  paywall and Settings, and from App Store Connect)

## Hosting

This repository is designed to be published with GitHub Pages.

## Analytics

Google Analytics should be added to the privacy policy page only after the GA4 Measurement ID is created. Keep analytics limited to the website; the MetaClean iOS app remains analytics-free for the current MVP unless explicitly reviewed and approved.
